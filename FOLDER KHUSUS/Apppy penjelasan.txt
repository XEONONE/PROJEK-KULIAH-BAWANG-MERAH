```python
def tugas_cnn_gpu(img_bgr):
    img_rgb = cv2.cvtColor(cv2.resize(img_bgr, (224, 224)), cv2.COLOR_BGR2RGB)
    pred_cnn = model_cnn.predict(np.expand_dims(img_rgb, axis=0))[0]
    ...
```
PENJELASAN TUGAS CNN:
- `cv2.resize`: Gambar dipaksa menjadi kotak 224x224 agar muat ke mulut AI.
- `cvtColor`: Tkinter membaca BGR, AI CNN minta RGB, maka dikonversi warnanya.
- `np.expand_dims`: Menambahkan sumbu batch (syarat mutlak input keras).
- `predict()`: AI mengeluarkan array tebakan.
- `np.argmax(pred_cnn)`: Mencari tebakan terbesar. Hasilnya kemudian dipasangkan ke dictionary warna/teks di Blok 4.

```python
def tugas_svm_cpu(img_bgr):
    img_gray = cv2.cvtColor(cv2.resize(img_bgr, (224, 224)), cv2.COLOR_BGR2GRAY)
    clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
    img_gray = clahe.apply(img_gray)
    glcm = graycomatrix(img_gray, distances=[1], angles=[0], levels=256, symmetric=True, normed=True)
    ...
```
PENJELASAN TUGAS GLCM+SVM:
- Berbeda dari CNN, GLCM tidak butuh warna. Gambar diubah ke Grayscale.
- `createCLAHE`: Gambar dinaikkan ketajamannya (Contrast Equalization) supaya urat-urat kulit bawang terlihat jelas oleh komputer.
- `graycomatrix`: Mencari keterhubungan antar piksel sejauh 1 piksel (distances=1) pada sudut datar 0 derajat (angles=0).
- `graycoprops`: Matriks GLCM diekstrak menjadi 4 nilai: Contrast, Correlation, Energy, dan Homogeneity.
- Keempat nilai tekstur ini dilempar ke `model_svm.predict()` untuk digolongkan mutunya. Nilai kepastian probabilitas (Confidence) dihitung menggunakan jarak antar garis (decision_function).
